# Roadmap

1. **v5 integration draft:** native recorder service bridge, UI recording button and SQLite metadata reconciliation.
2. **Build gate:** prebuild and compile; fix Expo module discovery and package placement.
3. **Device validation:** 1m/5m, rotations, background, screen lock, incoming calls, stop/restart, file playback.
4. **Recovery:** reconcile unfinished session and segment files after process death, plus notification actions.
5. **STT pipeline:** secure upload/authentication, queue/retry, timestamp alignment, dedup and summaries.
